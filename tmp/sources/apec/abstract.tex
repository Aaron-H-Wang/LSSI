\textbf{Abstract}: 
Compact core loss equations are essential tools in magnetic component design, but existing approaches trade accuracy against interpretability. Empirical models such as the Steinmetz Equation (SE) yield compact expressions of limited accuracy, while machine learning methods achieve high accuracy as black-box predictors. This paper bridges the gap with a Sparse Identification of Nonlinear Functions (SINF) framework, which casts core loss modeling as a data-driven symbolic regression problem and recovers unknown equations directly from measured data, without presuming a functional form. First, a comprehensively expanded library of symbolic candidate terms far richer than the SE is constructed. Second, the governing terms are isolated from this library by sparse regression. Third, the coefficients of the retained terms are refined with an AdamW optimizer to maximize accuracy while suppressing spurious contributions. On experimental data of Fair-Rite 95 within a wide operating range, SINF recovers an explicit equation with only $7$ active terms out of $103$ candidates, achieving a MAPE of $1.56\%$ and an $R^2$ of $0.9997$. The proposed SINF thus provides a compact and highly accurate solution for magnetic characterization and design.
