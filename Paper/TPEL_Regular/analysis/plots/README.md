# Independent Figure Scripts

Each result figure is generated by one independently runnable Python script.
Every multi-material result uses the same left-to-right order: **FR78, FR79,
FR95**. No in-panel letter or number labels are drawn.

The numerical calculations are separated from figure formatting. The scripts
read `../results_summary.json` and the material-local `predictions.csv` files;
they do not retrain LSSI or any baseline. Run the existing
`../build_regular_assets.py` only when those numerical files must be refreshed.

From this directory, generate one figure with, for example:

```powershell
python plot_03_lssi_validation.py
```

or regenerate every figure with:

```powershell
python run_all_plots.py
```

The main adjustable constants (`FIGSIZE`, `DPI`, point size, colors, crop boxes,
and output stem) are placed near the top of each script. All outputs are written
to `../../figures` in 600-dpi PNG and editable SVG formats, except the legacy
measurement/datasheet composite, which is a PNG crop of the original COMPEL
bitmap.

Script-to-figure mapping:

- `plot_01_measurement_agreement.py`: measurement versus datasheet comparison.
- `plot_02_operating_domains.py`: measured frequency-flux coverage.
- `plot_03_lssi_validation.py`: held-out predicted-versus-measured parity.
- `plot_04_residual_histograms.py`: train/test residual distributions.
- `plot_05_residual_vs_flux.py`: train/test residuals versus flux density.
- `plot_06_residual_vs_frequency.py`: train/test residuals versus frequency.
- `plot_05_method_comparison.py`: same-split MAPE comparison.
- `plot_06_radar_comparison.py`: one aggregate three-material radar comparison.
- `plot_07_sparse_coefficient_evolution.py`: ten sparse-coefficient trajectories, with the common retained support highlighted.
- `plot_08_raw_parameter_evolution.py`: raw internal-parameter trajectories for the active LSSI mechanisms.
- `plot_07_common_structure.py`: retained-term contributions.
- `plot_08_seed_robustness.py`: optional three-seed repeatability; it is not
  included by `run_all_plots.py` until seeds 1 and 2 have been retrained with
  the current 40,000-epoch regularized protocol.

The two evolution scripts read the material-local `parameter_history.csv` files
exported by `2. LSSI/lssi_multimaterial.py`. Re-run each material wrapper when
the optimizer, training schedule, or random seed changes; the plotting scripts
themselves do not retrain the model.

Run `../analyze_training_convergence.py` after training to regenerate the
machine-readable late-stage convergence audit in
`../convergence_diagnostics.csv` and `../convergence_diagnostics.json`.

The result figures retain the Letter's plotting grammar: Times New Roman (with
metric-compatible serif fallbacks), Computer Modern or STIX mathematics,
black dashed grids, red zero/ideal references where applicable, and the same
SE/RF/FNN/SSI/LSSI palette. The residual diagnostics also retain the Letter's
train/test colors. Material titles are the only panel identifiers; no embedded
subplot numbers are added.
